B4 : Submit Contact Form 

Valid Request : 
curl -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"name\":\"username\",\"email\":\"user@gmail.com\", \"message\":\"Hello There!\"}"
Expected : 
The contact submitted is accepted and stored.
Expected Status : 
201

Missing Name Request : 
curl -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"email\":\"user@gmail.com\", \"message\":\"Hello There!\"}"
Expected Response : 
{
    "error": "Name is required"
}
Expected Status : 
400

Invalid email Request : 
curl -X POST http://localhost:5000/api/contact -H "Content-Type: application/json" -d "{\"name\":\"username\",\"email\":\"gmail-com\", \"message\":\"Hello There!\"}"
Expected Response : 
{
    "error": "Invalid email format"
}
Expected Status : 
400

The Express application contains global error-handling middleware.

HTTP status is 500.
